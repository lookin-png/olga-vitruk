# Ольга Витрук — авторские интерьерные образы

Публичный сайт: https://lookin-png.github.io/olga-vitruk/

Статический сайт на HTML, CSS и JavaScript. Галерея содержит 124 интерьерные визуализации; изображения и шрифты хранятся в `assets/`.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Для обновления замените файлы сайта и отправьте коммит в `main`.

## Заявки

Форма готовит текст для Telegram; посетитель самостоятельно отправляет сообщение. Избранные изображения сохраняются в браузере посетителя.

## Материалы

Изображения являются интерьерными концепциями. Реальный материал и технологию изготовления согласуют отдельно. Изображения, портрет и подпись не предоставляются под открытой лицензией.
